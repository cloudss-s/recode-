# recode(,) — 溝通媒介互動實驗室
> Communication Media Archive & Experimental Interaction Laboratory

「在即時通訊普及以前，人們透過電線脈衝、以太電波與光線開闔傳遞訊息。從三種逐漸淡出的溝通媒介出發，重新認識物理信號如何跨越空間，被編譯、發射、接收與解讀。」

## 三大核心溝通媒介與物理機關

### 01. 電報機（MK-IV Telegraph Console）｜ 實色金屬・機械結構・發報銅鍵
* **拉絲金屬與機械總成**：採用實色金屬質地、四角沉頭螺栓與立體倒角設計。
* **實體黃銅發報鍵**：按下時按鍵下沉 4.5px，放開時彈簧阻尼回彈；支援滑鼠按壓、行動端觸控與鍵盤 **空白鍵 (Spacebar)** 快速敲擊。
* **原生純音合成**：使用 Web Audio API 即時生成 750Hz 純淨正弦波電報短長音（Dit / Dah），無須外掛音訊檔。
* **即時打孔紙帶流（Ticker Tape Waterfall）**：輸入或發送密碼時，紙帶向左物理頓挫推進，即時印製打孔點劃（`•` 與 `▬`）及對應英文字母。
* **防呆防錯機制**：即時偵測中文字元並彈出優雅警示框，支援一鍵清除與複製反饋。

### 02. 無線電廣播（FM Receiver · 88–108 MHz）｜ 懸浮玻璃・星盤調諧・示波器
* **半透明懸浮磨砂玻璃**：採用 24px 背景模糊、微高光折射邊框與多層次景深。
* **雙軌調諧系統**：提供橫向線性頻率刻度滑尺（金色指針）與 360° 類比調諧旋鈕。
* **動態載波示波器 Canvas**：
  - **偏離電台**：示波器呈現即時逐幀演算的灰白大氣電離層雜訊微粒（`○ SCANNING / STATIC NOISE`）。
  - **對準頻道**：雜訊衰減收斂，波形凝聚為光滑純淨的草綠色正弦波（`● TUNED LOCK`）。
* **三大站內模擬頻道探索**：
  - `FM 92.5 MHz`：深空脈衝信號（低頻週期性電波）
  - `FM 98.6 MHz`：媒介檔案廣播（歷史口述通訊錄音）
  - `FM 104.3 MHz`：即時文字廣播（結合瀏覽器語音合成發聲）

### 03. 燈光信號（海事燈塔光學台 Lighthouse Beacon）｜ 燈塔透鏡・海平線光束・光電受光
* **海事燈塔暗室光學台**：融合海事燈塔導航與夜間視覺信號通信。
* **旋轉透鏡燈室（Fresnel Lens Lantern Room）**：左側呈現燈塔透鏡發射端，發射時亮起高能草綠光暈（`#5ED642`）。
* **海平線光束傳導長廊**：中央光路即時射出高指向性光束貫通空間。
* **對岸哨站受光孔（Coastal Watchtower Sensor）**：右側哨站感光管同步感應亮起，即時逐字還原解碼字母。
* **雙模傳輸機制**：
  - **手動快門**：按住快門射出強光束，放開即刻熄滅阻斷。
  - **自動航海摩斯序列**：嚴格依照國際標準時鐘（點 120ms、劃 360ms、暗間隔 120ms、字母間隔 360ms）閃爍，消除連續長亮缺陷。

## 關鍵技術與架構
* **純前端架構**：零外部依賴、純 HTML5 / CSS3 / Vanilla JavaScript。
* **Web Audio API**：原生合成 750Hz 正弦電報音與機械快門繼電器脆響，具備全域靜音開關。
* **HTML5 Canvas 2D**：逐幀數學動態繪製電離層白雜訊與 AM/FM 正弦載波。
* **Web Speech API**：文字轉語音廣播朗讀。
* **極致 RWD 響應式排版**：從 390px 手機直式視窗到 4K 寬螢幕完美自適應，零橫向滾動溢出。
* **無障礙考量**：支援 `prefers-reduced-motion` 與鍵盤快捷鍵。
